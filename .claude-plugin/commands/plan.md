# /plan — 产品规划流

用户输入需求池/季度目标 → 多模型优先级评分 → 路线图与里程碑 → 用户任务流与 MVP 切片 → Sprint 任务拆分

## 使用场景

- "帮我排一下需求优先级"
- "Q2 要做这几个功能，怎么规划"
- "做一个产品路线图"
- "帮我拆一下 Sprint"

## Skill 链路

1. **优先级引擎** — 对需求池进行多模型优先级评分
2. **路线图规划** — 制定路线图与里程碑
3. **用户故事地图** — 拆解用户任务流与 MVP 切片
4. **迭代规划** — Sprint 任务拆分

## 示例

```
/plan Q2 提升用户留存
/plan 帮我排优先级
/plan 规划一下今年的产品路线图
```

## 输出

- 优先级排序结果
- 路线图（含里程碑）
- 用户故事地图
- MVP 切片方案
- Sprint 规划
