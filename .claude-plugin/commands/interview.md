# /interview — 访谈全流程

用户输入访谈目标 → 明确关键假设 → 结构化访谈提纲 → 洞察提炼

## 使用场景

- "想验证某个想法怎么做访谈"
- "帮我设计访谈提纲"
- "访谈记录整理出来了，帮我总结"
- "针对 XX 假设设计访谈"

## 子命令

- `/interview prep [目标]` — 仅准备访谈提纲
- `/interview summarize [记录]` — 仅总结访谈

## Skill 链路

1. **识别假设** — 明确要验证的假设
2. **访谈脚本** — 设计访谈提纲
3. **访谈总结** — 提炼洞察

## 示例

```
/interview 验证 AI 写作助手是否解决用户痛点
/interview prep 针对高优先级假设设计访谈
/interview summarize 用户访谈记录已整理
```

## 输出

- 访谈目标
- 关键假设
- 结构化访谈提纲
- 访谈总结
- 洞察清单
- 新的假设
