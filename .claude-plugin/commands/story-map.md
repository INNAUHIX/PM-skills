# /story-map — 用户故事地图专项

从 Epic、路线图目标或关键场景出发，整理用户任务流、故事清单和 MVP 切片。

## 使用场景

当你已经有 Epic 或路线图，但还没准备好直接写 PRD 时使用：
- `帮我拆一个用户故事地图`
- `这个 Epic 的 MVP 怎么切`
- `把路线图拆成故事`

## Skill 链路

1. **user-story-mapping** — 拆用户任务流、用户故事和版本切片

## 示例

```
/story-map 用户分享能力
/story-map 会员体系重构
/story-map AI 写作助手首个 MVP
```

## 输出

- 用户任务流
- 用户故事清单
- MVP / V1 / V2 版本切片
- 可继续写 PRD 的候选故事列表
- 推荐进入 `/write-prd` 的故事
