# /write-prd — PRD 全流程

用户输入模糊需求 → 完整 PRD 文档 → 多角度评审 → HTML 可交互原型 → 埋点规范 → 综合复评

## 使用场景

- "帮我写一个 XX 功能的 PRD"
- "要做用户分组功能，PRD 怎么写"
- "帮我评审一下这个 PRD"
- "我想做个原型"

## Skill 链路

1. **识别假设** — 明确需求背后的假设
2. **PRD编写** — 编写完整 PRD
3. **评审委员会** — 多角度 PRD 评审
4. **原型制作** — 制作 HTML 可交互原型
5. **埋点规范** — 制定埋点规范

## 入口模式

- `from-idea` — 从想法开始
- `from-discovery` — 从需求发现结果开始
- `from-story-map` — 从用户故事地图开始

## 示例

```
/write-prd 做一个用户分组功能
/write-prd from-idea 实现一个 AI 助手功能
/write-prd from-story-map 用户分享功能的 PRD
```

## 输出

- 完整 PRD 文档
- 评审意见
- HTML 原型
- 埋点规范
- 建议下一步行动
