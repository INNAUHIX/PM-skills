# /tracking-spec — 埋点规范专项

从功能需求或业务指标出发，定义事件、参数、上报时机和验收标准。

## 使用场景

当你已经有功能方案，需要补全数据采集规范时使用：
- `帮我给这个功能设计埋点`
- `写一个埋点文档`
- `定义这条漏斗要采什么数据`

## Skill 链路

1. **tracking-spec-writer** — 设计指标、事件、参数和验收标准

## 示例

```
/tracking-spec 用户分享功能
/tracking-spec 新注册流程转化漏斗
/tracking-spec 会员页埋点设计
```

## 输出

- 埋点规范文档
- 事件清单和参数定义
- 上报时机说明
- 验收清单
