# /roadmap — 快速路线图

从目标或需求出发，快速优先级评分 → 输出路线图（简化版）。

## 使用场景

当你需要快速制定一个路线图，但不需要拆到 Sprint 任务时使用：
- `帮我做一个 Q3 路线图`
- `这些功能怎么排版本`
- `制定一个 6 个月的规划`

## Skill 链路

1. **demand-prioritization-engine** — 对需求快速优先级评分
2. **pm-roadmap-planner** — 生成季度路线图（简化版）

## 示例

```
/roadmap Q3 提升付费转化率
/roadmap 新增 15 个功能需求
/roadmap 下半年产品规划
```

## 输出

- 快速优先级评分表
- 季度路线图（含里程碑、依赖和风险）
