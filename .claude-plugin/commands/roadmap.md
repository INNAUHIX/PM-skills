# /roadmap — 快速路线图

用户输入需求/目标 → 快速优先级评分 → 路线图（简化版）

## 使用场景

- "帮我画一个快速路线图"
- "Q3 要达成这个目标，怎么安排"
- "只需要一个简单的版本规划"

## Skill 链路

1. **优先级引擎** — 快速优先级评分
2. **路线图规划** — 制定简化版路线图

## 与 /plan 的区别

- `/plan` — 完整规划，含用户故事地图、Sprint 拆分
- `/roadmap` — 快速出路线图，适合时间紧迫或只需要高层规划

## 示例

```
/roadmap Q3 提升付费转化率
/roadmap 快速出一个半年路线图
```

## 输出

- 优先级评分
- 路线图（含里程碑）
- 建议下一步行动
