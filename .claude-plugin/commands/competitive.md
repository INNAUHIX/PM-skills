# /competitive — 竞品分析流程

从竞品名单出发，系统分析市场格局，找到差异化定位，提炼价值主张。

## 使用场景

当你需要分析竞争格局时使用：
- `分析 XX 市场的竞品`
- `我们的产品和竞品比有什么优势`
- `帮我找差异化切入点`

## Skill 链路

1. **competitive-strategy** — 分析市场格局和竞品定位
2. **strategy-canvas** — 多维度竞争曲线分析和 ERRC 差异化行动
3. **value-proposition** — 基于差异化方向提炼价值主张

## 示例

```
/competitive 在线文档工具市场
/competitive Figma 竞争对手分析
/competitive 企业协作工具
```

## 输出

- 竞品情报表（含定位、功能、优劣势）
- 战略画布分析（含 ERRC 行动建议）
- 差异化价值主张
