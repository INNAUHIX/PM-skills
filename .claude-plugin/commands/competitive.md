# /competitive — 竞品分析流

用户输入竞品名单/市场 → 竞争格局分析 → 竞争维度画线 + ERRC 行动 → 差异化价值主张

## 使用场景

- "分析 XX 市场的竞争格局"
- "我们产品和 XX 竞品比有什么优势"
- "想了解某个细分市场的玩家"
- "怎么做差异化定位"

## Skill 链路

1. **竞品简报** — 收集竞品信息，分析竞争格局
2. **策略画布** — 绘制竞争维度，ERRC 行动
3. **价值主张** — 提炼差异化价值主张

## 示例

```
/competitive 在线文档工具市场
/competitive 我们和飞书、Notion 的竞争格局
/competitive B2B SaaS 市场的差异化机会
```

## 输出

- 竞品分析报告
- 竞争格局图
- 策略画布（ERRC 行动）
- 差异化价值主张
- 建议下一步行动
