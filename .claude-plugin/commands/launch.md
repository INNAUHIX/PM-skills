# /launch — 发布全流程

已确认交接范围 → 工程交接 → 灰度策略 + 发布检查 + 回滚方案 → 上线复盘 + 行动项

## 使用场景

- "v2.5.0 要发布了，帮我走一遍"
- "准备上线一个新功能"
- "要做灰度发布"
- "发布后怎么复盘"

## Skill 链路

1. **工程交接** — 整理交接包
2. **发布流程** — 制定灰度策略、发布检查、回滚方案
3. **复盘学习** — 上线复盘与行动项

## 示例

```
/launch v2.5.0
/launch 准备上线用户分组功能
/launch 做一个灰度发布计划
```

## 输出

- 工程交接包
- 灰度策略
- 发布检查清单
- 回滚方案
- 上线复盘报告
- 行动项列表
