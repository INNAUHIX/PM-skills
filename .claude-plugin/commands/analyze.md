# /analyze — 数据分析流

用户输入数据问题/上传数据 → 数据检验 + 假设推断 → A/B 测试方案 + 止损规则 → 实验结果分析 + 行动建议

## 使用场景

- "DAU 最近一周下降了 15%"
- "帮我分析一下用户转化数据"
- "怎么设计 A/B 测试"
- "实验结果出来了，帮我分析"

## Skill 链路

1. **数据分析** — 数据检验、假设推断、结果分析
2. **实验设计** — A/B 测试方案、止损规则

## 示例

```
/analyze DAU 最近一周下降了 15%
/analyze 用户转化漏斗分析
/analyze 设计一个注册流程的 A/B 测试
/analyze 实验结果出来了，帮我看看
```

## 输出

- 数据分析报告
- 假设推断
- A/B 测试方案
- 止损规则
- 实验结果分析
- 行动建议
