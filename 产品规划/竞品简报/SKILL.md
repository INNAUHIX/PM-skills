## 背景（Context）

本 Skill 基于 **波特竞争战略（Porters Generic Strategies）** 和 **蓝海战略（Blue Ocean Strategy）**。

### 这个方法解决什么问题

进入市场前或面对竞品压力时，团队需要回答：**我们在哪里可以赢？** 不是功能对比表，而是系统的竞争定位分析和差异化机会识别。

### 核心框架

- **来源**：Michael Porter《竞争战略》+ Chan Kim & Rene Mauborgne《蓝海战略》
- **核心逻辑**：先看格局（有哪些玩家），再看位置（我们能站哪），最后定策略（怎么赢）
- **与其他 Skill 的关系**：
  - 本 Skill 输出的差异化方向 → 「value-proposition」Skill 据此提炼差异化主张
  - 本 Skill 输出的竞争定位 → 「strategy-canvas」Skill 据此做多维度竞争分析

### 适用边界

✅ **适用**：新市场进入前的竞争格局分析；产品线扩展或收缩决策
❌ **不适用**：单次功能点的竞品对比表（用「strategy-canvas」的局部分析）
❌ **不适用**：竞品技术实现细节分析（超出产品经理范畴）

# 产品线规划：看清市场格局，找到定位机会

## 步骤一：竞品信息收集

### 做什么

对每个竞品收集以下维度信息：

```markdown
## 竞品情报表

| 产品 | 公司 | 定位 | 核心功能（Top3） | 目标用户 | 定价 | 优势 | 劣势 | 数据来源 |
|------|------|------|----------------|---------|------|------|------|---------|
| [产品A] | ... | ... | ... | ... | ... | ... | ... | ... |
```

**信息收集优先级：**
- P0（必须）：产品定位、核心功能、目标用户
- P1（最好）：定价、用户规模、评分
- P2（有则更好）：融资情况、组织架构、战略方向

---

## 步骤二：多维矩阵分析

### 定位矩阵

根据两个核心维度绘制矩阵，定位各竞品位置：

```
                        功能丰富
                           │
         ┌─────────────────┼─────────────────┐
         │  [产品A]       │   [产品B]       │
         │  高端全功能     │   企业定制      │
   价格  ├─────────────────┼─────────────────┤  价格
    高   │  [产品C]       │   [我们?]       │  低
         │  专业垂直       │   [待定位]      │
         └─────────────────┼─────────────────┘
                           │
                        功能精简
```

**常用定位维度组合：**
- 价格（高/低）× 功能丰富度（丰富/精简）
- 目标用户（企业/个人）× 产品复杂度（简单/复杂）
- 成熟度（新锐/成熟）× 定价（低价/高价）

### 空白点识别

```markdown
## 市场空白点分析

| 象限 | 定位 | 现有产品 | 潜在需求强度 | 我们可行性 |
|------|------|---------|------------|-----------|
| 价格高+功能精 | 高端小而美 | 少 | 中 | 需评估 |
| 价格低+功能丰 | 性价比之王 | 无 | 高 | 技术可行？|
```

## 步骤三：差异化机会识别

### 差异化维度清单

| 维度 | 含义 | 示例 |
|------|------|------|
| **功能差异化** | 竞品没有但用户需要的功能 | 离线模式、跨平台同步 |
| **体验差异化** | 同样的功能，体验更好 | 更快的响应、更简洁的界面 |
| **用户群差异化** | 聚焦竞品未覆盖的用户群 | 中小企业、自由职业者 |
| **价格差异化** | 同样的价值，更低的价格 | 免费+增值模型 |
| **信任差异化** | 更可信、更安全、更合规 | 金融级安全认证 |
| **生态差异化** | 与其他产品更好的集成 | 开放API、插件市场 |

### 机会评分矩阵

```markdown
## 差异化机会评分

| 机会 | 用户需求强度 | 竞品满足度 | 我们可行性 | 综合评分 | 优先级 |
|------|------------|---------|-----------|---------|--------|
| 离线模式 | 高（用户强需求） | 低（竞品弱） | 高（技术可行） | ⭐⭐⭐⭐⭐ | P0 |
| 低价切入 | 中（价格敏感） | 中（竞品价格混战） | 高（成本可控） | ⭐⭐⭐⭐ | P1 |
```

## 步骤四：竞争策略选择

### 四大策略框架

| 策略 | 说明 | 适用条件 | 风险 |
|------|------|---------|------|
| **差异化** | 找到独特定位，避开正面竞争 | 有明显差异化优势 | 差异化不够时两头不靠 |
| **细分聚焦** | 聚焦特定用户群或垂直场景 | 有明确的细分市场壁垒 | 市场天花板低 |
| **成本领先** | 提供更低价格或更高性价比 | 有成本优势或规模效应 | 价格战伤敌一千自损八百 |
| **聚焦深耕** | 在某一垂直领域做到最强 | 垂直领域有深厚积累 | 跨赛道扩张困难 |

### 策略选择决策树

```
我们有什么独特优势？
    │
    ├── 技术领先 ──→ 差异化（功能/体验）
    │
    ├── 用户关系深 ──→ 细分聚焦（忠诚用户群）
    │
    ├── 规模效应强 ──→ 成本领先
    │
    └── 资源有限 ──→ 聚焦深耕（单点突破）
```

### 策略落地建议

```markdown
## 推荐策略：[策略名称]

**核心定位语：**
[一句话说明我们是谁、服务谁、解决什么问题]

**差异化支柱：**
1. [第一差异点] — [具体说明]
2. [第二差异点] — [具体说明]
3. [第三差异点] — [具体说明]

**短期行动（0-3个月）：**
- [ ] [具体动作]

**中期行动（3-12个月）：**
- [ ] [具体动作]

**需要避免的定位：**
- [竞品名] 的打法（原因）
- [定位描述]（原因）
```

## 输出检查清单

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 竞品情报覆盖主要竞品 | 不遗漏重要玩家 |
| 2 | 定位矩阵有空白点 | 不是所有象限都满 |
| 3 | 每个空白点有可行性评估 | 不是纯理想分析 |
| 4 | 策略选择有明确依据 | 不是拍脑袋 |
| 5 | 有"这对我们意味着什么" | 每个结论都指向行动 |
| 6 | 差异化可落地 | 不是"更好的体验"这种空话 |

## 触发检查与兜底策略

### 🔍 触发条件检查

**进入标准流程的条件：**
- ✅ 用户提供了竞品名单（或产品类目/市场范围）

**进入兜底模式（满足任一）：**
- 🚨 用户说"分析竞品"但没有具体竞品名单
- 🚨 用户不清楚目标市场是什么
- 🚨 用户想要的是单产品的功能对比表（用「strategy-canvas」更合适）

**不触发本 Skill：**
- ⛔ 单产品多维度竞争分析（用「strategy-canvas」）
- ⛔ 技术实现对比（超出产品经理范畴）

### 🆘 兜底策略

**兜底触发**：没有竞品名单或目标市场信息。

```markdown
# [前置] 竞品分析 — 需要先确认这些

## 在开始分析之前，请先确认：

### 必须确认
1. **目标市场**：我们在分析哪个市场/赛道？
2. **主要竞品**：有哪些产品需要分析？（至少 3-5 个）
3. **分析目标**：这次分析想回答什么问题？

### 建议确认
4. 每个竞品的核心定位是什么？（一句话）
5. 我们的产品目前在这个市场中的位置？

---
如果竞品信息有限，我会基于已知信息进行分析，
空白部分标注为"待补充"，并给出补充信息的建议。
```
